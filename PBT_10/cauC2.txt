</tr>

<h2>1. Promise.all()</h2>

<p>
Resolve khi tất cả Promise thành công.
</p>

<p>
Reject ngay khi có một Promise thất bại.
</p>

<h3>Thực tế E-Commerce</h3>

<p>
Trang chi tiết sản phẩm cần:
</p>

<ul>
<li>Thông tin sản phẩm</li>
<li>Đánh giá</li>
<li>Tồn kho</li>
</ul>

<p>
Thiếu một dữ liệu thì trang không thể hiển thị đầy đủ.
</p>

<pre>
async function loadProductPage(id){

    const [
        product,
        reviews,
        stock
    ] = await Promise.all([

        fetch(`/api/products/${id}`)
            .then(r => r.json()),

        fetch(`/api/reviews/${id}`)
            .then(r => r.json()),

        fetch(`/api/stock/${id}`)
            .then(r => r.json())

    ]);

    return {
        product,
        reviews,
        stock
    };

}
</pre>

<h3>Kết quả</h3>

<pre>
Product OK
Reviews OK
Stock FAIL

=> Promise.all() reject ngay
</pre>

</div>

<div class="section">

<h2>2. Promise.allSettled()</h2>

<p>
Chờ tất cả Promise hoàn thành.
</p>

<p>
Không quan tâm thành công hay thất bại.
</p>

<p>
Luôn resolve.
</p>

<h3>Thực tế Dashboard Admin</h3>

<p>
Dashboard gọi nhiều API:
</p>

<ul>
<li>Doanh thu</li>
<li>Đơn hàng</li>
<li>Khách hàng</li>
<li>Sản phẩm bán chạy</li>
</ul>

<p>
Một API lỗi không nên làm hỏng cả dashboard.
</p>

<pre>
const results =
    await Promise.allSettled([

        fetch("/api/revenue")
            .then(r => r.json()),

        fetch("/api/orders")
            .then(r => r.json()),

        fetch("/api/customers")
            .then(r => r.json()),

        fetch("/api/top-products")
            .then(r => r.json())

    ]);

console.log(results);
</pre>

<h3>Kết quả</h3>

<pre>
[
 { status:"fulfilled", value:{...} },

 { status:"fulfilled", value:{...} },

 { status:"rejected", reason:Error },

 { status:"fulfilled", value:{...} }
]
</pre>

<p>
Dashboard vẫn hiển thị được phần dữ liệu còn lại.
</p>

</div>

<div class="section">

<h2>3. Promise.race()</h2>

<p>
Promise nào hoàn thành đầu tiên sẽ quyết định kết quả.
</p>

<h3>Thực tế: Timeout API</h3>

<p>
Nếu API quá chậm (>10 giây) thì huỷ request.
</p>

<pre>
function timeout(ms){

    return new Promise((_, reject)=>{

        setTimeout(()=>{

            reject(
                new Error("Timeout")
            );

        }, ms);

    });

}

const response =
    await Promise.race([

        fetch("/api/products"),

        timeout(10000)

    ]);
</pre>

<h3>Kết quả</h3>

<pre>
API trả trước 10 giây
=> Resolve

Timeout xảy ra trước
=> Reject
</pre>

<p>
Đây là use case phổ biến nhất của Promise.race().
</p>

</div>

<div class="section">

<h2>4. Promise.any()</h2>

<p>
Chỉ cần một Promise thành công.
</p>

<p>
Các Promise lỗi được bỏ qua.
</p>

<p>
Chỉ reject khi tất cả cùng thất bại.
</p>

<h3>Thực tế: CDN Fallback</h3>

<p>
Ảnh sản phẩm được lưu trên nhiều CDN.
</p>

<p>
Lấy ảnh từ server nào phản hồi thành công trước.
</p>

<pre>
const image =
    await Promise.any([

        fetch(
            "https://cdn1.shop.com/image.jpg"
        ),

        fetch(
            "https://cdn2.shop.com/image.jpg"
        ),

        fetch(
            "https://cdn3.shop.com/image.jpg"
        )

    ]);

console.log(image);
</pre>

<h3>Kết quả</h3>

<pre>
CDN1 FAIL
CDN2 FAIL
CDN3 SUCCESS

=> Promise.any() resolve
</pre>

<p>
Chỉ cần một CDN hoạt động là đủ.
</p>

</div>

<div class="section">

<h2>So sánh trực quan</h2>

<h3>Promise.all()</h3>

<pre>
A ✓
B ✓
C ✗

=> Reject
</pre>

<h3>Promise.allSettled()</h3>

<pre>
A ✓
B ✓
C ✗

=> Resolve
=> Trả kết quả của cả 3
</pre>

<h3>Promise.race()</h3>

<pre>
A (3s)
B (1s)
C (5s)

=> B thắng
</pre>

<h3>Promise.any()</h3>

<pre>
A ✗
B ✗
C ✓

=> Resolve bằng C
</pre>
